## Descripción del Proyecto

**FB Abogados** es un sitio web institucional y plataforma interactiva de captación legal diseñada bajo estándares de desarrollo web moderno, estética *luxury* y protección avanzada de seguridad anti-spam. 

Permite a los usuarios consultar especialidades legales, agendar asesorías directas vía WhatsApp y realizar un **diagnóstico preliminar de su caso en línea**.

---

## Características Principales

- **Especialidades Jurídicas Destacadas**:
  - **Derecho Civil**: Contratos, arrendamientos, propiedad y recuperación de bienes.
  - **Derecho Familiar**: Divorcios, pensión alimenticia, custodia e intestados/sucesiones.
  - **Derecho Penal**: Defensa jurídica, denuncias, amparos y atención ante MP.
  - **Derecho Mercantil**: Cobranza judicial/extrajudicial, pagarés y contratos comerciales.

- **UltraSecurityEngine (Módulo de Seguridad Integrado en JavaScript)**:
  - **Protección Anti-Bots & Honeypot**: Trampas invisibles para neutralizar envíos automáticos de spam.
  - **Validación de Identidad Real**: Filtro inteligente de teclazos aleatorios (*gibberish*), nombres falsos y patrones repetidos (ej. `asdf`, `qwerty`, `aaaa`).
  - **Validador Estricto de Teléfono**: Verificación de formato numérico de 10 dígitos y bloqueo de secuencias sintéticas (ej. `1234567890`, `0000000000`).
  - **Sanitización XSS / Anti-Inyección**: Desinfección de entradas de texto y neutralización de caracteres de control.
  - **Filtro Anti-Spam Publicitario**: Bloqueo automático de mensajes que contengan enlaces externos o spam comercial.
  - **Human Velocity & Throttle**: Control de tiempo mínimo de lectura y periodo de enfriamiento entre envíos (5 segundos).

- **Integración Directa con WhatsApp Business**:
  - Transmisión instantánea de diagnósticos y datos de contacto formateados directamente al teléfono oficial de la titular (**+52 729 140 4674**).

- **Diseño Luxury Responsive & SEO Optimizado**:
  - Estilo visual de alta gama con tonos oro pulido (`#d4af37`) y azul noche (`#0b0d10`).
  - Tipografía ejecutiva Google Fonts (`Cormorant Garamond`, `Montserrat`, `Great Vibes`).
  - Adaptabilidad total a dispositivos móviles, tablets y monitores de alta resolución.
  - Metaetiquetas Open Graph (OG) y estructura HTML5 semántica para mejor posicionamiento web.

## Instalación y Despliegue

### Ejecución Local
1. Clona este repositorio:
   ```bash
   git clone https://github.com/GITALETS/abogados-fb.git
   ```
2. Abre la carpeta del proyecto.
3. Haz doble clic en `index.html` o abre el archivo en cualquier navegador web moderno (Chrome, Edge, Firefox, Safari).

### Despliegue en GitHub Pages
1. Sube este repositorio a tu cuenta de **GitHub**.
2. Ve a **Settings** > **Pages**.
3. En **Source**, selecciona la rama `main` (o `master`) y la carpeta `/ (root)`.
4. Guarda los cambios. En un par de minutos tu sitio estará en línea de forma gratuita.
